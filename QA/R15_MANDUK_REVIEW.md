## 1. 확인 범위

`R15_FIRST_ANSWER_CODEX.md`를 기준으로 공식 홈페이지, 이용약관, 결제·환불 정책을 읽었습니다. 아래의 ‘확인’은 공개 문구를 확인했다는 뜻입니다. 로그인, 분석 실행, 무료 횟수 차감, 권한 부여, 주문, 결제, 환불은 실행하지 않았습니다. 공개 안내만으로 서버의 실제 동작을 검증했다고 판단하지 않습니다.

R15는 마케팅 프런트엔드의 공개 사례 소개와 공식 서비스 이동만 다룹니다. 사용자 원본, 백엔드, API, 인증, 권한, 결제 및 상품 정책 변경은 이 작업의 범위가 아닙니다. 본 문서는 해당 영역의 변경이나 운영 배포를 요청·승인하지 않습니다.

### 사례 인용 시 지켜야 할 구분

- 1.4%와 11.6%의 단위는 **음식점 중 주점 비중**입니다. 전체 점포 또는 인구의 비율로 바꾸지 않습니다.
- 2026년 10월은 공개 사례 묶음의 표기입니다. 2026-11-18은 이번 공개 페이지 확인일입니다. 개별 지표의 원자료 기준일, 산출 분모, 원자료 버전은 별도로 확인하지 못했습니다.
- 대표 지점 반경 500m 표기를 행정동 인구 등 다른 단위의 통계에 일괄 적용하지 않습니다. 해당 비율이 어떤 원자료와 정확한 공간 경계로 산출되었는지는 상세 검토가 필요합니다.
- 주점 비중 하나만으로 저녁 수요의 부재를 새로 판정하지 않습니다. ‘주의’와 낮 상권에 관한 해석은 공식 공개 사례에 귀속시키고, 현장 확인 질문은 R15의 안내로 구분합니다.
- 잠실 사례의 별도 상세 URL은 확인하지 못했습니다. 공식 홈페이지를 출처로 연결하며 임의의 사례 식별자·앵커·쿼리를 만들지 않습니다.
- Basic 19,900원은 **기본가**로 표시할 수 있습니다. 개인별 프로모션 자격·최종 가격은 공식 서비스에서 확인해야 합니다. 9,900원 프로모션은 30일 상품의 조건이며, 미승인 7일 실험 가격과 섞지 않습니다.

## 3. Manduk 확인 요청 — 향후 연동이 필요할 때

아래는 검토할 질문 목록입니다. 확정된 API 스키마, 구현 요청, 새로운 상품 정책이 아닙니다. 현재 R15에는 이를 가정한 상태나 동작을 만들지 않습니다.

### 판정과 근거

1. 실제 판정의 허용 상태와 표시 문구를 확인해 주세요. 특히 근거 부족·근거 상충 시 `cannot-judge`에 해당하는 상태가 존재하는지, 그 사유를 어디까지 보여주는지 확인이 필요합니다. 판정 불가를 실패·나쁜 판정·결제 필요로 바꾸지 않아야 합니다.
2. 각 근거에 붙일 지표명, 수치 단위, 공간 범위, 비교 대상, 출처, 자료 기준일 및 조회 시점을 확인해 주세요. 서로 다른 날짜·단위의 근거를 하나의 결과 시점이나 반경으로 합쳐 표시하지 않아야 합니다.
3. 지역별 제공 범위, 자료 지연, 누락, 관측값과 추정값의 구분을 확인해 주세요. 임대료·매출 등의 추정치를 개별 매물·가게의 실제 값으로 표현하지 않도록 표시 원칙이 필요합니다.
4. 판정 옆에 남겨야 할 핵심 한계와 다음 현장 확인 항목의 출처·책임 범위를 확인해 주세요. 주의 신호나 불확실성을 구매 유도 때문에 숨기지 않아야 합니다.

### Free·비로그인 정책

- 비로그인으로 가능한 단계와 최초 인증이 필요한 시점, 익명·회원의 사용 한도, 횟수 갱신 시점을 확인해 주세요.
- 전체 공개 판정 1개의 선택 기준과 다른 판정의 공개 범위가 실제 서버 정책과 일치하는지 확인해 주세요. 공개 홈페이지의 안내를 새 권한 계약으로 복제하지 않습니다.
- `/explore`, `/place`, `/analyze` 각 시작 경로의 인증 요구와 지역 범위를 확인해 주세요. 공식 페이지 방문이나 실패한 요청이 이용 횟수에 영향을 주는지도 실제 검증 전 확인이 필요합니다.

### 결과 복귀와 선택형 이용권 비교

- 향후 실제 결과에서 이용권 비교로 이동한 뒤 돌아오려면, 서비스가 공식 지원하는 결과 식별·보관·접근 권한과 복귀 경로가 필요합니다. 만료된 결과, 비로그인 결과, 다른 사용자의 결과에 대한 동작도 확인해 주세요.
- 결제·권한 변경 후 표시할 결과와 권한의 근거는 공식 서버여야 합니다. 마케팅 페이지가 구매 성공이나 권한 활성화를 추정하지 않습니다.
- 실제 구매 링크 또는 심화 기능 진입을 연결하려면 지원되는 공식 경로, 최종 가격·자격 확인 위치, 인증 후 복귀 규칙을 먼저 확인해 주세요. 임의의 `returnUrl`, 상품 ID, 결과 ID, 플랜 쿼리를 만들지 않습니다.
- **현재의 대안:** `https://localscope.co.kr/explore`, `https://localscope.co.kr/place`, `https://localscope.co.kr/analyze` 고정 경로를 별도 공식 서비스임을 알리고 새 탭으로 엽니다. 사용자 위치·답변·분석 상태를 URL이나 저장소로 전달하지 않습니다. 이용권 안내는 공식 공개 페이지로 연결하고 결제는 공식 서비스에 맡깁니다.
